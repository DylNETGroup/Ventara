# Ventara

Official Ventara download and update endpoint.

This repository intentionally does **not** contain the Ventara application source code. Official compiled versions are published from the repository's **Releases** page.

## Downloads

Open **Releases** and choose the package for your platform:

- Windows — installer (and portable build when published)
- macOS — DMG / ZIP
- Linux — AppImage

Ventara's built-in updater also reads its release metadata from this repository.

## Development source

Ventara's development source, tests, build tools, and private release tooling are maintained separately and are not published here.
